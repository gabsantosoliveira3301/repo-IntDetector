# IntDetector 

Aplicação desktop desenvolvida em **Java** com interface gráfica projetado para analisar, processar e mostrar caracteristicas de 10 váriaveis Int de uma vez: 

* média
* impar
* par
* menor
* maior

## ✨ Funcionalidades

O programa processa os 10 valores inseridos e exibe instantaneamente:
- **Maior valor** do conjunto.
- **Menor valor** do conjunto.
- **Média aritmética** entre todos os números.
- Quantidade e listagem de números **Pares**.
- Quantidade e listagem de números **Ímpares**.

## Como Executar no Eclipse IDE

1. **Clone ou baixe** este repositório em sua máquina.
2. Abra o **Eclipse IDE**.
3. Importe o projeto: Vá em `File` > `Import...` > `General` > `Existing Projects into Workspace` e selecione a pasta do projeto.
4. Localize a classe principal que contém o método `main`.
5. Clique com o botão direito sobre o arquivo, vá em **Run As** > **Java Application**.
